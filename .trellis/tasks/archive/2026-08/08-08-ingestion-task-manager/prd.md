# 门户新增 Data Ingestion 任务管理模块

## Goal

在 Part 2 分析门户中新增「数据摄入任务管理」模块，让分析师不必回到命令行
（`agentcore invoke`）就能创建、调度、观察和复盘 Part 1 的选品数据摄入任务。

## 用户故事

作为门户用户（analyst），我希望：

1. **创建任务**：在门户里发起一个摄入任务（输入选品指令/商品关键词等 prompt），
   支持同时创建多个任务并行执行，互不阻塞。
2. **调度模式**：创建时可选「一次性」（立即执行一次）或「定期」（按周期重复执行，
   例如每天/每小时/cron 表达式）；定期任务可暂停/恢复/删除。
3. **观察执行**：任务执行过程中（单次运行约 2~5 分钟），我可以：
   - 查看运行进度（阶段/步骤级别，如：启动 → 浏览器抓取 → 测算 → 入库）；
   - 查看关键日志（agent 的关键动作与结论，非全量 debug 日志）；
   - 打开 Browser Live View，实时观看云端浏览器正在抓取的画面
     （AgentCore Browser 的 DCV 直播流）。
4. **复盘结果**：任务运行结束后，我可以看到本次抓取的结果统计
   （如：候选商品数、判定通过/拒绝数、耗时、状态），并能下钻查看明细表
   （本次运行写入 `product_candidates` / `selection_verdicts` 的记录）。

## Requirements

### 功能需求

- R1 任务 CRUD：创建 / 列表 / 详情 / 删除；定期任务支持启用与暂停。
- R2 并行：多个任务（及同一定期任务的多次运行）可并发执行，互不干扰；
  每次运行使用独立的 Runtime 会话。
- R3 调度：一次性任务创建后立即触发；定期任务按用户设定的周期自动触发，
  周期表达形式至少支持「每 N 小时 / 每天固定时刻」，可扩展 cron。
- R4 运行观测：
  - 每次运行有独立的 run 记录：状态（排队/运行中/成功/失败）、开始/结束时间；
  - 进度与关键日志以事件流形式展示，运行中自动刷新；
  - 运行期间可查看 Browser Live View；浏览器会话结束后 Live View 入口关闭并
    给出提示（presigned URL 最长 300 秒，需支持过期刷新）。
- R5 结果统计与明细：run 详情页展示统计卡片，并可展开当次运行写入数仓的
  明细记录（分页表格）。
- R6 权限：模块所有 API 都必须经门户既有 Keycloak 登录态保护，未登录不可访问。

### 非功能需求与约束

- C1 前端风格沿用 Part 2 已定型的「量化工作台」暗色风格（冷石墨底 + 青柠
  accent #c9f158、IBM Plex、Phosphor 图标），不引入新的视觉体系。
- C2 不改变 Part 1 现有命令行调用方式（`agentcore invoke` / local_test 仍可用）。
- C3 文档、代码注释、commit message 全部中文；文档中不出现真实 AWS 端点/账号，
  用占位符；密钥只指向 `.deploy/secrets.env`。
- C4 部署保持幂等：纳入 Part 2 `scripts/deploy.sh`（或独立脚本），可重复执行。
- C5 数仓沿用共享 Aurora（RDS Data API / 同 VPC Lambda 直连既有模式），
  不新建数据库集群。
- C6 Live View 的 presigned URL 必须由服务端生成（SigV4 凭证不下发到浏览器）。

## Acceptance Criteria

- [ ] AC1 门户新增「任务管理」入口；能创建一次性任务，创建后列表可见且状态流转
      为 排队/运行中 → 成功（或失败），全程无需命令行。
- [ ] AC2 同时创建 ≥2 个任务，二者并行执行且各自的 run 记录、日志、结果互不混淆。
- [ ] AC3 能创建定期任务（如每天 09:00），调度器按时触发新 run；暂停后不再触发，
      恢复后继续。
- [ ] AC4 运行中打开 run 详情：能看到进度阶段与关键日志自动更新；能打开
      Live View 看到云端浏览器实时画面；URL 过期后可一键刷新重连。
- [ ] AC5 运行结束后统计卡片正确（候选数/判定数/耗时/状态），明细表能列出
      当次运行写入的 `product_candidates` 与 `selection_verdicts` 记录。
- [ ] AC6 未携带有效 Keycloak token 调用任务管理 API 返回 401/403。
- [ ] AC7 `part2_chat_portal/scripts/deploy.sh`（或新增脚本）幂等部署全部新资源；
      重跑不报错。
- [ ] AC8 `实验手册.md` 与两个 README 同步更新新模块的部署与使用说明。

## 边界（本期不做）

- 不做任务结果的对比分析/图表趋势（沿用聊天分析侧能力）。
- 不做多用户隔离与配额（workshop 单用户 analyst）。
- 不做失败自动重试策略（失败可手动重跑）。
- Live View 只读观看为主；「接管控制」(take/release control) 作为可选加分项，
  非验收必需。
