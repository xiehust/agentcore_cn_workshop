# 降低 eBay Demo 选品门槛并补充入库样例

## Goal

降低 eBay UK/US 演示选品流程的 R1 月销门槛与产品点门槛，使 workshop 更容易产生候选商品；发布新版 Runtime 后执行多轮真实选品入库，并把可复用的实际入库提示词写入实验手册。

## Requirements

- `product-selection-ebay`（UK）与 `product-selection-ebay-us`（US）的月销硬门槛统一改为严格大于 1；月销等于或低于 1 时仍按现有语义写入 `PASS`。
- 两份 Skill 的产品点门槛统一改为严格大于 `0.0005`；等于或低于该值时判定为 `排除`。
- 当前价格门槛、月销估算口径、产品点公式、市场结构规则、黑名单、入库协议和 UK/US 站点隔离均保持不变。
- 更新所有受影响的 Skill 文案、伪代码和字段说明，避免同一文件中残留旧门槛。
- 更新实验手册中的门槛、公式解释和示例；明确这些是为 demo 扩大样本量而设的宽松阈值。
- 重新发布 Part 1 Runtime，使云端执行使用新 Skill。
- 至少发起 4 次真实入库请求：UK 两次、US 两次；每次处理前 2 个非广告、一口价、全新商品，共尝试 8 个商品。为控制时长与配额，按两批执行，每批并行一个 UK 和一个 US 请求。
- 记录每次实际使用的完整提示词、执行结果和新增入库数；将实际提示词加入实验手册，供学员复制运行。
- 不清理或覆盖既有业务数据；允许同一商品因重复演示产生新判定记录，候选表仍遵循当前数据库约束。

## Acceptance Criteria

- [x] UK/US 两份 Skill 中 R1 月销门槛均为 `> 1`，产品点门槛均为 `> 0.0005`，且旧值在相关规则段落中无残留。
- [x] 价格、公式、市场结构、黑名单和站点币种规则未被意外修改。
- [x] 实验手册准确解释新门槛，并列出本次真实执行过的 UK/US 入库提示词。
- [x] Part 1 Runtime 成功发布，部署状态可用。
- [x] 完成 4 次 Runtime 入库调用及 1 次计划内补跑；每次均保存文本结果，数仓有本批次新增判定。
- [x] 按调用前后计数和基线后记录证明实际写库结果；外部抓取/响应流/上下文超限如实记录，未伪造候选成功。
- [x] 文档和 Skill 一致性扫描、`git diff --check` 通过。

## Constraints

- 所有沟通、文档和提交信息使用中文。
- 不在仓库中记录真实账号、端点或凭证；实验手册提示词可记录，运行标识和云资源 ARN 不写入文档。
- eBay 页面和反爬状态属于外部依赖，验收要求是执行并如实验证入库，而不是保证每次都产出 `采集` 候选。
